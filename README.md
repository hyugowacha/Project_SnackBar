# Project_SnackBar
## Unity 3D 개인 프로젝트

------

### 프로젝트 소개📌

장르: 3D 캐주얼 방치형 경영

개발 기간: 

개발 인원: 1명

주요 파트: 

------

타겟층:	10~30대 캐주얼 게임 이용자 (짧은 시간에도 가볍게 즐길 수 있는 게임을 선호하는 유저)

출시 플랫폼:	모바일 (Android / iOS)

핵심 게임플레이:	손님 방문 → 주문 → 음식 제작 → 판매 → 골드 획득 → 시설/직원 업그레이드
                • 방치 중에도 자동으로 재화가 생산되며, 접속 시 오프라인 보상 획득

성장 구조:	수익 증가 → 시설 확장 → 신규 메뉴/직원 해금 → 더 많은 손님 → 수익 증가 
          • 지역 확장과 콘텐츠 해금을 통한 장기 성장
          
BM:	광고 + 인앱 결제 혼합 모델
    • 광고 시청 → 오프라인 보상 2배, 즉시 보상 등
    • 인앱 결제 → 재화 패키지, 성장 패키지, 광고 제거 등
    • 꾸미기 상품 → 캐릭터/시설 스킨 등
